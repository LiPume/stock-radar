## 已知技术债与未完成项

- RSI 计算参考算法是 Wilder 版本，尚未与同花顺终端计算初值一致性做实测比对。
- 参考脚本并非高可靠生产接口模块，还未具备历史缓存、交易日历、自动备份、长期调度或微信推送；这些在完整开发阶段实现。
- 同花顺和 AKShare 的实际权限、版本、稳定性随服务变化，不保证公开接口永久免费的可用性。
- GitHub Pages 无法运行 Python 后端；正式部署需另一后端运行环境。
