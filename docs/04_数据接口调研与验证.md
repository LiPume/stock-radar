## 2. 同花顺 REST 历史接口（A 股）

参考：

- 快速开始：<https://fuyao.aicubes.cn/docs/quickstart/>
- 历史行情：<https://fuyao.aicubes.cn/docs/api-reference/prices/>
- 批量说明：<https://fuyao.aicubes.cn/docs/mcp/tools/get_a_share_prices_historical_batch/>
- API Key：<https://fuyao.aicubes.cn/admin/>
- 发布源项目：<https://github.com/Hithink-Tech-Org/Financial-API>

**端点**：`GET https://fuyao.aicubes.cn/api/a-share/prices/historical-batch`

| Query | 类型 | 示例 | 说明 |
|---|---|---|---|
| `thscodes` | string | `600519.SH,688525.SH` | 逗号分隔，最多 10 只（去重前检查上限） |
| `interval` | string | `1d` | 日/周/月，V1 只用 `1d` |
| `start` / `end` | int | Unix 毫秒 | 按 10 年最大窗口约束；用上海时区日期转毫秒 |
| `adjust` | enum | `forward` | `none`/`forward`/`backward`，默认前复权 |

HTTP Header：`X-api-key: <用户实际 Key>`；REST 可以从本地 Python/云端后端调用，*不要求运行在 SuperMind 云研究环境里*。

成功响应（结构描述，不是实时数据）：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "interval": "1d",
    "adjust": "forward",
    "item": [{
      "thscode": "600519.SH",
      "timestamp": 1767110400000,
      "item": [{"date_ms": 1767110400000, "open_price": 1.0, "high_price": 1.0,
                "low_price": 1.0, "close_price": 1.0, "volume": 100, "turnover": 100.0}]
    }]
  }
}
```

**注意**：以上价格和时间只用于说明字段结构。真正探测必须从响应中取值；绝不能写死或声称是当前行情。

逐股验证时，`code=0` 的响应仍可省略未知或不支持的证券分组。合法空组的 `timestamp` 为 `null`、`item` 为空数组。有记录的分组按 K 线日期升序返回。去重后仅一个目标且类型不支持时返回 `3004`，其他全无有效标的的请求返回 `3001`。[批量历史 K 线](https://fuyao.aicubes.cn/docs/mcp/tools/get_a_share_prices_historical_batch/)

故障类：无 Key 或失效，参数错误，超限/权限不足，非 A 股代码，历史为空，返回结构变更，网络超时，日线滞后。探测报告应保留 HTTP 状态、API 错误码/消息（经过脱敏），禁止保存 Key。

## 3. B 股 AKShare

AKShare 1.20.65 官方文档将新浪 B 股历史行情列为 `stock_zh_b_hist_sina`，日线参数为 `period="daily"`。提示文件引用的 1.4.92 镜像使用旧名 `stock_zh_b_daily`，该入口直接返回日线。复现时记录安装版本和实际入口。[当前官方行情文档](https://akshare.akfamily.xyz/data/stock/stock_quote.html#b) · [旧版接口文档](https://akshare-hh.readthedocs.io/en/latest/data/stock/stock.html)

```python
import akshare as ak
bars = ak.stock_zh_b_hist_sina(
    symbol="sh900901", period="daily",
    start_date="20260101", end_date="20261120", adjust="qfq"
)
```

示例代码为 `900901.SH -> sh900901`、`200xxx.SZ -> sz200xxx`。返回交易日、OHLC 和以股计的成交量。B 股接口的 `turnover` 表示换手率，同花顺 A 股的同名字段表示成交额。价格可选不复权（空串）、前复权（`qfq`）或后复权（`hfq`）。

该源依赖第三方网页数据，不具备商业 SLA，频繁请求可能遭限流/封禁；不要每分钟扫描。少量持仓一天 1–3 次请求、缓存增量日线并按供应商规则控制速率。

## 5. 直接使用本包的测试脚本

```bash
# 完全离线演示，不会调用任何金融数据源
python scripts/market_probe.py --provider demo

# 有同花顺 Key 后测试 A 股
export HITHINK_FINANCE_API_KEY='...'
python scripts/market_probe.py --provider hithink --a 600519.SH --days 240

# 安装可选依赖并测试 B 股
python -m pip install -e '.[probe]'
python scripts/market_probe.py --provider akshare-b --b 900901.SH --days 240

# 同测（每个源至少一个样本）
python scripts/market_probe.py --provider all --a 600519.SH --b 900901.SH
```

默认输出 `reports/probe_result.json`，日志不可包含 Key。`--export-csv` 可选择保存真实历史数据以便和同花顺截图对齐（文件不提交 Git）。

## 6. 如何决定是否可以进入完整开发

**GO**：目标账号 A 股样本真实返回且过去 100+ 日数据正常；B 股目标代码有可用接口；明确个人额度足以覆盖 6–30 只持仓每天 1–3 次；当地目标运行环境可访问这些 API。

**CONDITIONAL GO**：A 股通过、B 股临时不可用。可先实现 A 股监控，B 股独立显示“未接入/错误”，不能展示虚假 B 股信号。

**NO-GO**：Key 不可申请/费用无法接受、长期取数空缺、指标不能对齐，暂时不开发生产提醒；先替换 Provider 或对接能合法使用的数据。

## 7. 费用与服务限制

- 同花顺当前公开规则未设置累计调用次数上限，会按服务负载动态限流。HTTP 429 或业务码 `4001` 均表示频率超限。`2001` 对应凭据缺失或无效，`2003` 对应权限不足。本次已核实当前 Key 对批量历史日 K 的权限，个人账号的价格与长期权益仍待确认。[接口总览及错误码](https://fuyao.aicubes.cn/docs/api-reference/overview/)
- Server酱 Turbo 的官网 FAQ 当前列免费用户 **每天最多 5 条**：<https://sct.ftqq.com/docs/getting-started/faq/>。可以把同时命中的多股合并成 1 条通知，但超额仍需处理。
- GitHub Pages 可托管静态网站，无法托管持久运行的 Python 服务和 SQLite。
- SuperMind 问财本地不支持的说明：<https://quant.10jqka.com.cn/view/help/4>（搜索“问财接口是否支持本地接口调用”）。
